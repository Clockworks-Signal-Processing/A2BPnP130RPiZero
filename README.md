# PnP130PiOS
This code is for Raspberry Pi Zero 2W target, created from the RP2040 code version; Version 1.3.0 of A2B PnP for RP2040 was created from the 1.1.0 RP2040 app.
Claude was used to create this from the RP2040 version.  The claude.md file is included in the repo as it may be helpful if you wish to make further modifications to the code.
There are  ports of the stack (and console program) for WIN32 and RP2040.  If you don't see them please ask and we'll sort it out.
