# PnP130PiOS
This code is for Raspberry Pi Zero 2W target. This was created from the RP2040 code version.  version 1.3.0 of A2B PnP for RP2040 was created from the 1.1.0 RP2040 app.
Claude was used to create this from the RP2040 version.  The cuade.md file is included here as it may be helpful if you wish to make further modifications to the code.
There are also ports for WIN32 and RP2040.  If you don't see them please ask and we'll sort it out.
